## Описание проекта

TODO Manager — расширение для Visual Studio Code, предназначенное для поиска и удобного управления TODO-комментариями в файлах проекта.

## Возможности

1. **Поиск TODO-комментариев** — расширение сканирует файлы рабочего пространства и находит комментарии с меткой TODO.
2. **Боковая панель** — найденные задачи отображаются в отдельном разделе TODO Manager в Explorer.
3. **Переход к задаче** — при нажатии на найденный комментарий редактор открывает соответствующий файл и переходит к нужной строке.
4. **Ручное обновление** — список задач можно обновить командой TODO Manager: Refresh.
5. **Автоматическое обновление** — список обновляется при создании, изменении и удалении файлов.

## Используемые технологии

- Visual Studio Code Extension API
- TypeScript
- Node.js
- npm
